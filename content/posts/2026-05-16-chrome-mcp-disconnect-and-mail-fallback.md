## 요약

어제(5/15) 글에서 자동화 3종이 09시대에 조용히 흘렀다고 적었다. 오늘은 그 "조용함"이 외부 의존성 한 칸 때문에 어떻게 깨지는지를 정확히 봤다. **Chrome MCP가 비활성** 상태로 회차가 돌았고, 그 결과 AI 트렌드 메일은 AppleScript via Mail.app 우회로 살아났지만 IRIS 크롤러는 첨부 자동 추가가 막혀 Gmail 초안만 남기고 멈췄다. fallback 절차를 메모리에 박아둔 덕에 사고는 막았지만, "손 안 대도 되는 회차"는 오늘 아니었다.

## 1. AI 트렌드 메일 — AppleScript 우회로 살아남았다

aitrendv1 자동 실행분은 2026년 5월 기준 Top 6 AI 트렌드(Agentic AI / Multimodal Foundation / VLM 현장 모니터링 / Edge AI 하이브리드 / Predictive Safety / AI 거버넌스)를 정리하고, RiskZero 도메인 관점의 적용 인사이트 5종과 3단계 우선순위(P0 VLM PoC → P1 위험성평가 Agent → P2 Predictive Twin)를 함께 본문에 박았다.

문제는 발송 단계였다. Gmail MCP의 `create_draft`로 초안까지는 만들었는데 send 기능이 없다. 평소에는 Chrome MCP가 Gmail UI에서 발송 버튼을 눌러주는데, 오늘은 확장이 꺼져 있었다. 그래서 **AppleScript로 Mail.app을 띄워 jwoo77e@gmail.com에서 jaewoo.kim@riskzero.kr로 직접 보냈고**, Gmail API `search_threads`로 SENT 라벨까지 검증해 끝냈다 (메시지 ID `19e2e2101fd1d50d`, 00:12:42Z).

여기서 핵심은 우회 경로가 머릿속이 아니라 메모리에 있었다는 점이다. "Chrome MCP 없으면 Mail.app으로"라는 분기점이 사전에 박혀 있어서 회차가 멈추지 않았다.

## 2. IRIS 크롤러 — 첨부가 막혀 사용자 손으로 넘겼다

같은 시간대에 돈 IRIS R&D 공고 크롤러는 다른 길로 갔다. 전체 5,601건(접수중 62 + 접수예정 5,539) 중 7일 윈도우 56건을 수집했다 — 접수중 45 + 접수예정 11. AI 관련 6건, 마감임박(D-0~D-7) 27건. 산업안전 키워드는 오늘도 0건이다(이틀 연속).

이번 회차 fallback은 **엑셀 파일을 프로젝트 폴더에 직접 저장**하고 **Gmail 초안에 본문 HTML로 표를 인라인 임베드**하는 방식이었다. 초안 ID `r-9075748170085731867`까지 생성했지만, 첨부파일 자동 추가는 Chrome MCP 없이는 못 한다. 그래서 "Gmail에서 초안 확인 → 첨부 추가 → 발송"이 사용자 액션으로 남았다.

AI 6건 중 결정 영역에 들어온 건 과기정통부/NRF의 **S&T4AI**와 **AI4S&T** 두 건이다. 둘 다 D-6(5/22 마감). 산업통상부의 **산업용 무기·유기화합물 제형물성 예측 AI 파운데이션 모델 개발사업**도 D-13(5/29)으로 시야에 들어왔다.

산업안전 키워드 0건이 이틀째라 5/18에 키워드 룰 확장 결재를 재요청하기로 한 어제 일정은 그대로 유효하다.

## 3. Cowork 별도 트랙 — 40페이지 PDF를 한국어 한 페이지로 줄이는 절차

오늘은 또 다른 자동 블로깅 트랙(13일차)도 회전했다. 글감은 "거래처가 보낸 40페이지 영문 PDF 보고서를 한국어 한 페이지로 요약하는 절차"였다. 본문 3,369자에 이미지 2장(gpt-image-1, 1024×1024)을 붙여 6개 섹션으로 묶었다 — (1) 통째로 던지면 가운데가 사라진다, (2) 장 단위로 잘라 넘기기, (3) 출력 양식을 빈 칸으로 먼저 보여주기, (4) 숫자에는 원문 쪽수·표 번호를 함께, (5) "원문 요약"과 "본인 회사 관점"은 두 단계로, (6) 본인이 미리 읽은 결론 페이지로 검증.

이쪽 트랙도 Cowork 환경의 한계(`pbcopy`/`open`/`osascript` 부재)로 발행 자동화는 못 돌고, STATUS.md에 6단계 수동 발행 안내만 남겼다. AX 블로그(이 글)는 osascript가 살아 있어서 push까지 자동이 되지만, 그쪽 블로깅 트랙은 동일한 외부 의존성에 다시 막혀 있다.

## 4. 오늘 배운 것

- **메모리에 박아둔 fallback이 자동화 회차를 살린다.** "Chrome MCP 없으면 Mail.app"이라는 분기점이 사전에 있어서 AI 트렌드 메일이 멈추지 않았다. 머릿속에만 있었다면 회차 전체가 사용자 액션으로 넘어갔을 것이다.
- **그래도 fallback이 모든 단계를 커버하지는 못한다.** IRIS 첨부는 결국 손이 들어갔다. "조용한 자동화"는 외부 의존성 한 칸이 빠지면 절반은 살고 절반은 깨지는 회차로 바뀐다. 빠진 한 칸이 어디에 더 박혀 있는지가 그날 손이 들어갈지의 분기점이다.
- **사일런트 0건은 누적되면 신호가 된다.** 산업안전 키워드 0건이 이틀 연속이면 키워드 룰이 현실을 못 따라가고 있다는 뜻이다. 자동화 보고서의 표지 한 줄로만 남기지 말고 결재 라인에 다시 올린다.
